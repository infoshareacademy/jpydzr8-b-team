    polecenie:
        - python (python3) -m venv [nazwa_srodowiska]
2. aktywacja utworzonego środowiska wirtualnego w pkt. 1
    polecenie:
        - Windows: [nazwa_srodowiska]\Scripts\activate
        - Linux/macOS: source [nazwa_srodowiska]/bin/activate
3. instalacja django w aktywowanym środowisku wirtualnym
    polecenie:
        - pip (pip3) install django
4. (opcjonalnie) sprawdź czy django poprawnie zainstalowano
    polecenie:
        - pip list
5. przy pomocy poniższego polecenia utwórz projekt django:
    - django-admin startproject [nazwa_projektu]9. 
6. przejdź do utworzonego w pkt.5 projektu django
    polecenie:
        - cd [nazwa projektu]
7. będąc w katalogu projektu, uruchamiam serwer po raz pierwszy
    polecenie:
        - python manage.py runserver
    po pierwszym uruchomieniu serwera, automatycznie w projekcie tworzy sie plik z bazą danych sqlite
8. zatrzymaj serwer Ctrl + C (jesli uruchomiony) 
9. utwórz aplikację w projekcie
    polecenie:
        - python manage.py startapp [nazwa aplikacji]
    zostanie utworzony folder z aplikacją oraz zawartością do pracy
